# Databricks Sales Data Analytics

## Project Overview
This project focuses on analyzing retail sales data using Databricks SQL to identify business insights and understand sales performance.

The project explores how data can be organized, queried, and visualized to support data-driven decision-making.

## Tools & Technologies
- Databricks
- Unity Catalog
- SQL
- Databricks Genie
- AI/BI Dashboards
- GitHub

## Dataset
The project uses a retail sales dataset containing information about products, sales amounts, quantities sold, regions, sales dates, and product categories.

## Business Questions

1. What is the overall sales performance?
2. Which five products generate the highest sales revenue?
3. Which regions perform best in terms of sales revenue?
4. How does sales revenue change month by month?
5. What is each product category's contribution to total sales revenue?

## SQL Analysis
SQL queries are used to calculate total sales revenue, total quantity sold, sales records, product performance, regional performance, monthly sales trends, and category-wise revenue contribution.

## Databricks Genie
Databricks Genie is explored to ask business questions using natural language and compare its responses with SQL query results.

## AI/BI Dashboard
An interactive dashboard is designed to present key performance indicators and sales trends through visualizations.

**Dashboard highlights:**
- Total Sales Revenue
- Total Quantity Sold
- Distinct Products
- Total Sales Records
- Sales by Region
- Top Five Products
- Monthly Sales Trend
- Sales by Product Category

## Key Learnings
- Understanding Unity Catalog and data organization
- Writing SQL queries for business analysis
- Using aggregation, grouping, sorting, and date functions
- Exploring data with natural-language questions
- Presenting business insights through dashboards
